mqttc

A small, fast, open source desktop MQTT client. Connect to a broker, watch topics stream in, inspect payloads, and publish, all from one window.

First launch

The builds are not code signed yet, so your OS warns once.

macOS says the app is damaged. Drag it to Applications, then run this once in Terminal:

xattr -cr /Applications/mqttc.app

Windows shows a SmartScreen dialog. Click More info, then Run anyway.
