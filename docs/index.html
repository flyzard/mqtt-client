First launch

macOS

“mqttc is damaged” Drag it to Applications, then run once in Terminal:

xattr -cr /Applications/mqttc.app
Windows

SmartScreen Click More info, then Run anyway.

Linux

No gate. The AppImage needs chmod +x first.

Connecting

Paste a broker URL

A bare host defaults to tcp on 1883. Credentials and TLS go in the URL:

mqtts://user:pass@broker.example:8883
Then

Topics fill in as messages arrive. / filters them, ↑↓ walk them, ⌘↵ publishes. Passwords live in the OS keychain.
