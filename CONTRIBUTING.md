# Contributing

Thanks for taking an interest in mqttc. Bug reports, fixes and small,
focused features are welcome.

## Before you start

- Open an issue for anything larger than a bug fix so the approach can be
  agreed before you spend time on it.
- Keep pull requests to one change. Separate refactors from behaviour changes.

## Working on the code

See the Development section of the README for the toolchain. Before opening
a pull request, run `task check` and make sure it passes.

Match the surrounding style: Go code is `gofmt`-clean, the frontend uses
Svelte 5 runes and Tailwind utilities, and UI work follows `DESIGN.md`.
